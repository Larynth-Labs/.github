# Contributing

Thanks for helping. Each repository's own CONTRIBUTING file, where present, takes precedence over this one.

- Open an issue before a large change so we can agree on the approach.
- Keep pull requests small and focused, with a clear description of what changed and why.
- Never commit API keys, webhook secrets, phone numbers of real people or call recordings.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report security issues as described in [SECURITY.md](SECURITY.md).
